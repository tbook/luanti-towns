# Re-export the Issue 196 buildings

Run from the Towns mod checkout after saving and closing TownsWorkshop:

```sh
python3 tools/issue196_import/export.py \
  --world "$HOME/Library/Application Support/minetest/worlds/TownsWorkshop"
```

The script takes a read-only SQLite snapshot and captures the current Workshop
copies at their recorded bounds. A scratch-engine roundtrip checks every node
name and `param2`. It refreshes the shepherd hut and demo house schematics; the
four stock village assets remain their authored stock versions. Door state is
written to `.lua` sidecars and restored by the normal placement code. The
source world is never modified.

To re-export only some buildings, pass `--only`, e.g.
`--only shepherd_hut`.

## The farm is not exported

The outskirts farm (`schematics/outskirts/farm.mts` and `farm.lua`) is
authored in code, not captured from the Workshop. The open-field farm (#282)
is generated by `tools/issue255_farm/build.py`. The fenced farm still in
TownsWorkshop (9x8x7 at 100,8,470) is stale, the pre-#282 design, and is
deliberately not exported. The farm is absent from `BUILDINGS`, and
`RETIRED_PATHS` in `export.py` makes the script refuse to write
`farm.mts` or `farm.lua` even if someone re-adds it. Do not re-add the farm
or edit those files from a capture; change the farm through `build.py`.
